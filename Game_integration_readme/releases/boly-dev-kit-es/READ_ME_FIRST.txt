BOLY - KIT DE INTEGRACION DE JUEGOS
===================================

1. Abre  index.html  en tu navegador web (doble clic).
   Es una guia interactiva, paso a paso. Siguela.
   (La guia tiene un boton para cambiar entre Espanol e Ingles.)

2. Los scripts de heartbeat que pegas en tu juego estan en la carpeta  scripts/
   (uno por motor: Unity / Godot / Unreal, mas una guia de configuracion de escenas).

3. boly-verify-win.exe  prueba tu build final en Windows -- la guia (Paso 5)
   explica exactamente como ejecutarlo.
